encodes is not lost with the files. Generated by inspection of
`server/src/tests`, not from memory.

The executed count is higher because several suites generate cases in loops.

**How to read this.** The "Asserted behaviour" column is the verbatim
`describe` titles of each file. They are the authors' own statement of what
the file protects, and they are the input to the new test architecture: every
row must be either re-expressed as a domain/invariant test against the
rebuilt system, or explicitly retired with a reason.
