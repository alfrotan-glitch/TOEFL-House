SANDBOX TOOLCHAIN (extension-less env: no pdo_pgsql, no composer, no pg).
Untracked helper dir; intentionally NOT committed. Survives sandbox
recycles only as untracked files — the pushed branch does not need it.

Recipe (all transports verified reachable 2026-09-05):
  PHP:   git clone --depth 1 --filter=blob:none --sparse
         https://github.com/NativePHP/php-bin ; sparse-checkout
         bin/linux/x64/php-8.3.zip ; unzip (static musl, NO dlopen, NO
         pgsql/xmlwriter/pcntl/posix). Run as /tmp/phpbin/php.
  PG:    npm pack @embedded-postgres/linux-x64 (PG 18.4 bins+libpq) ;
         symlink libX.so.M[.m] -> libX.so.M / libX.so ; initdb -U postgres
         --auth=trust ; pg_hba trust-all ; start on 127.0.0.1:5432 ;
         CREATE DATABASE toefl_house_test. Speed: synchronous_commit=off,
         fsync=off, full_page_writes=off (throwaway cluster).
  VENDOR: python3 .sandbox/vendor_fetch.py  (106 pkgs via codeload tarballs
         from composer.lock github refs; phpstan via api.github zipball)
         then  /tmp/phpbin/php .sandbox/gen_autoload.php  (psr4/psr0/
         token-scanned classmaps/files/installed.json+installed.php).
  PHPUNIT: vendor patch (RE-APPLY after every vendor rebuild):
         vendor/phpunit/phpunit/phpunit pre-flight list drops 'xmlwriter'
         (static php lacks it; used only by baseline writer + list-as-xml).
  TESTS: /tmp/phpbin/php vendor/phpunit/phpunit/phpunit  (phpunit.xml
         bootstrap tests/bootstrap.php auto-loads PgWire when needed).

PgWire TCP perf: socket TCP_NODELAY is mandatory (Nagle+delayed-ACK added
~40ms per protocol frame; migrate:fresh 64s -> 2s).
