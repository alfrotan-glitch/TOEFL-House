# Official brand assets

`toefl-house-logo.png` is the **official TOEFL House logo**, supplied by the
institute. It is the single canonical copy used by every branded surface in the
system (screens, print sheets, receipts, invoices, ID cards, certificates,
reports, favicon).

Rules:

- Do **not** redesign, redraw, recreate, approximate, recolour or distort it.
- Do **not** copy it elsewhere in the repository. Every consumer references it
  through `src/config/branding.ts` (`BRAND_LOGO_URL`).
- To update the branding, replace this one file, or edit
  `src/config/branding.ts` — nothing else should need to change.
