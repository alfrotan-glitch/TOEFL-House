# Public editorial content

`home.json`, `general.json`, `academic.json`, `special.json`, `guides.json` and `ui.json` hold existing English (`en`), Dari (`fa`) and Pashto (`ps`) public copy. `home.json` owns the localized home SEO titles and each course's localized name and short/fallback durations, plus its decorative glyph, keyed by the authoritative edge course ID; changing catalog order does not reassign them. Its three quick paths have their own ordered catalog with course IDs and English tags, and localized labels keyed by course ID. The compiler checks references, uniqueness and every locale's labels; changes to the number of quick paths require a coordinated design and content-contract review. The glyphs are trusted source graphics, not user-provided SVG; the compiler only accepts the current restricted path/circle/rect syntax. Changes to that syntax need a security review and compiler/test update. `ui.json` owns shared breadcrumbs, image alternatives, course-detail labels, admissions facts/fallbacks and practice interface labels. `special.json` owns the localized speaking and TOEFL duration displays alongside their course content. `academic.json` owns EAP metadata, fee/duration display and the explicit guide identity for each EAP book; the latter travels with the book rather than relying on a parallel renderer list. `general.json` owns the ordered stage catalog and localized stage data keyed by stage identity, including focus, description and fee; duration type belongs to the catalog. The compiler validates every locale against the catalog and the current five-stage/first-foundation policy. Program policy changes require explicit institutional review and an accompanying contract/test update, not simply a count change. These files contain no CMS records, private student data or credentials. Renderers remain responsible for escaping all content, mixed-script direction and accessible markup. Other short renderer-specific labels still live beside their renderers and have not yet been migrated.

`brand.webp.base64` contains the existing logo bytes, not a new externally routed Pages asset. `brand-asset.mjs` verifies its fixed SHA-256 and WebP signature before injecting the exact bytes and revision into the Worker. Replacing it deliberately requires brand-owner review, a new pinned checksum, tests, a complete package and release/rollback review; merely editing the base64 fails the build. Moving it to Pages assets would require separate provider-backed routing and manifest verification.

Edit all affected languages together. `content-compiler.mjs` checks locale and structural parity, rejects empty or whitespace-only localized strings, and builds compact JavaScript constants into the existing Worker; unequal list lengths may be legitimate for lists that the renderer does not index. `content-shape-contract.mjs` separately records required fields for major localized blocks and selected nested course/guide records, including retained editorial fields. It prevents deleting those fields or changing their basic JSON types in every locale at once; additional fields are allowed, and selected learning lists must be nonempty. Update the contract and tests deliberately when changing field ownership or approved content structure. This is not a complete nested schema or a public-CMS privacy projection. The sole string exception is an article's deliberately empty optional `program` association; whitespace-only values are not accepted. New optional fields require a deliberate schema and test change, not silently blank translations. The build also checks indexed list lengths and tuple widths, required guide structure, HTTPS book-source URLs, and course/guide links against the authoritative edge catalog. The catalog and practice counts are read without execution by `content-contract.mjs`; its deliberately narrow declaration syntax fails closed if the source changes or is ambiguous. If routes or renderer-indexed lists change, update their consumers and tests together; do not bypass the contract. These checks cover known dependencies, not every conceivable content error. Structural validation cannot establish correct translation, accuracy, accessibility or rights. Institutional and language review is still needed, especially for course descriptions, prices, test claims and publisher references. Do not change a course, source or translation simply to make a shape check pass.

After editing: `node cloudflare/site-v2/build.mjs`, `node cloudflare/site-v2/budgets.mjs`, the site/edge/analytics tests, and the isolated browser suite. Use `compare-worker-contract.mjs` with a trusted prior Worker when a change is meant to preserve output. That tool uses synthetic fixtures and cannot prove real Cloudflare routing, legacy rewriting, database isolation or deployed behavior. For screenshot matrices, use `node cloudflare/site-v2/visual-compare.mjs BEFORE AFTER --expect-worker=cloudflare/site-v2/dist/_worker.js --widths=320,390,768,1024,1440,1920 --expected-count=51` (use `--widths=390,1440` for full-page captures). The Worker is imported and executed: use only a trusted local build. The optional matrix check verifies expected filenames from its sitemap, not image authenticity, human review, viewport contents or deployed behavior; match the Worker digest and environment to the captured evidence. CI candidate screenshots use synthetic data and expire after seven days; arrange authorized durable evidence storage before claiming a complete audit.
